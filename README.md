# Cinema Prompting Studio

Open index.html to choose a workspace. Sightline turns a scene into timed beats with camera direction, lighting, sound and loop continuity. Copy a prompt or download it as plain text. Drafts are stored by the browser. English and Traditional Chinese are available in the launcher and Sightline. Changing languages changes the camera instructions and keeps your authored text.

FrameCraft and CinePrompt Studio are the supplied standalone modules. Their original interfaces load Tailwind CSS and Lucide from external CDNs.

The catalog folder contains the Possibility Apps cover and bilingual entry.
